# Архитектура

Маршруты Next.js остаются в корневом `app/`. FSD-код располагается в `src/`.
Названия `_pages` и `_app` используются в соответствии с рекомендациями FSD,
чтобы не конфликтовать с маршрутизаторами Next.js.

```text
app/                       # маршруты, layout и модуль базовых стилей
src/
  _pages/case-list/        # список дел
  _pages/case-details/     # обзор, документы, почта и общий контекст дела
  widgets/                # самостоятельные блоки страницы
    workspace-shell/      # навигация, шапка, область содержимого
    case-overview/        # сведения о деле и ближайший срок
    case-timeline/        # таймлайн
    case-navigation/      # переходы между отдельными страницами дела
    documents-browser/    # папки, поиск, сортировка, предпросмотр
    mail-browser/         # фильтры, поиск и цепочки переписки
  entities/legal-case/    # типы, демоданные, логика дат, элементы дела
  entities/case-document/ # документы и дерево папок конкретного дела
  entities/email-thread/  # цепочки переписки конкретного дела
  shared/
    ui/                   # Panel, Badge, элементы поиска и фильтрации
    lib/                  # форматирование дат
    api/                  # серверный Prisma-клиент
prisma/                   # схема, миграции, seed
```

Зависимости направлены сверху вниз: pages → widgets → features → entities → shared.
Между слайсами используются публичные `index.ts`, внутри слайса — относительные импорты.
В доменных типах нет зависимости от Prisma: интерфейс можно подключить к БД через адаптер данных.
Серверный `shared/api/db.ts` защищён `server-only`; он не экспортируется в клиентский граф.

Все стили — `*.module.scss`. Базовые правила ограничены классами корневого layout.
Tailwind и глобальные CSS-файлы не используются.

Страница пока использует фиксированный набор `demoCase` и дату `asOf`, поэтому открывается
без работающей БД. PostgreSQL подготовлен отдельно: миграции, идемпотентный seed и `db:check`.
Документы и почта показывают состояние подключения и учебные примеры. Запросы к Google
ещё не выполняются. Выборка материалов ограничена номером дела на серверной странице;
клиентский поиск работает только с переданными материалами этого дела.

Результаты UX-разбора и принятые решения: [ux-review.md](ux-review.md).

Источники: [FSD + Next.js](https://feature-sliced.design/docs/guides/tech/with-nextjs),
[Prisma + PostgreSQL](https://www.prisma.io/docs/orm/v7/core-concepts/supported-databases/postgresql).
